- (direction) Fast path: project owner granted autonomy on 2026-09-21; decisions modelled on Sure where relevant, popular maintained libraries preferred, open-source code quality.
- (constraint) Inherited from AGENTS.md and ADR 0001/0002: TypeScript 7, Hono, Vite+React, TanStack Router/Query, SQLite via Drizzle+libsql, Better Auth, Enable Banking, Vitest+Playwright, pnpm workspaces, one container, single entrypoint, no queue, API envelope and AppError, Zod at every boundary, integer minor units.
- (decision) Paradigm: modular monolith with ports and adapters. Domain logic is pure TS without Hono or DB; services own DB writes; routes are thin Hono adapters; connectors are adapters behind a port.
- (decision) Ledger service is the single writer of entries, valuations and balances; manual entry, file import and bank sync all go through it. Prevents three sources each inventing dedup and recompute.
- (decision) Connector port: two kinds, FileSource (parse bytes+options -> ParsedStatement) and BankConnector (institutions, startAuthorization, completeAuthorization, listAccounts, fetchStatement since, consent expiry). Both output ParsedStatement {transactions: NormalizedTransaction[], balance?, rejected[]}. Registry is a static list in one file, no dynamic loading.
- (decision) Sign convention diverges from Sure: entry amount signed from account point of view, negative = money leaving. Liability balances stored as positive outstanding debt; a liability's daily balance = previous - sum(amounts).
- (decision) Entries modelled like Sure delegated types: one entries table with kind transaction|valuation; transaction-only columns in transactions table keyed by entry_id; valuation kinds opening_anchor|reconciliation|current_anchor as in Sure.
- (decision) Dedup key computed once at ingest and stored: ext:<external id> when source provides one, else fp:<sha256 of date|amount|normalised label|occurrence index>. Unique index (account_id, source, dedup_key). Never recomputed on edit.
- (decision) Balances materialised per account per day; forward calculation for manual accounts from opening anchor, reverse from current anchor for linked accounts, as Sure Balance::ForwardCalculator/ReverseCalculator. Recomputed by the ledger inside the same DB transaction from earliest changed date.
- (decision) Ingestion pipeline order fixed: parse -> dedup -> write entries -> rules (epic 8) -> transfer matching (epic 5) -> balance recompute, one DB transaction per account. Recurring detection runs after commit.
- (decision) Money: no dinero.js. Money is {amount: integer minor units, currency: ISO code} with a branded MinorUnits type; formatting via Intl.NumberFormat fr-FR; user input parsed by one shared parseAmount function in @archant/data.
- (decision) IDs text UUID v4 from crypto.randomUUID; calendar dates ISO YYYY-MM-DD text; timestamps integer epoch ms UTC; today computed in APP_TIMEZONE (default Europe/Paris).
- (decision) Secrets at rest AES-256-GCM via node:crypto with ENCRYPTION_KEY env (32 bytes base64), stored as v1:iv:tag:ciphertext.
- (decision) Libraries: papaparse (CSV), ofx-js (OFX, zero deps, output parsed by Zod), QIF parser written in-house (no maintained lib, format trivial), jose (Enable Banking JWT RS256), pino with redact (logs), msw with onUnhandledRequest error (network in tests), i18next+react-i18next (interface), shadcn/ui+Tailwind 4, Recharts via shadcn charts, TanStack Table, react-hook-form+zod resolver, date-fns for date arithmetic, lucide-react icons.
- (decision) Pagination: offset with page and pageSize (default 50, max 200); bulk actions accept either ids or the same filter object as the list.
- (decision) Pending transactions: entries.pending flag; booked version replaces pending per story 10.4; pending excluded from cash flow but included in balance.
- (decision) Manual edits: transactions table stores locked_fields JSON array (as Sure enrichable locks); rules and providers skip locked fields.
- (decision) Transfers table links outflow and inflow transaction ids with kind; rejected_transfers table stores rejected pairs; as Sure.
- (version) Verified on npm 2026-09-21: papaparse 5.7.0, ofx-js 1.1.1, jose 6.2.12, pino 10.3.1, msw 2.15.0, i18next 26.4.2, react-i18next 17.0.14, recharts 3.10.1, tailwindcss 4.3.3, shadcn 4.21.0, react-hook-form 7.88.0, @hookform/resolvers 5.9.1, date-fns 4.4.0, @tanstack/react-table 9.2.4, @tanstack/router-plugin 1.168.x, better-auth 1.7.5, drizzle-orm 0.45.3, hono 4.13.8, @libsql/client 0.18.0, lucide-react 1.47.0, Node 24.19.
- (question) Rules epic 8 data model left to the project owner; spine only fixes that rules run inside the ingestion pipeline and respect locked_fields.
- (decision) Dedup keys moved to entry_keys table so one entry carries keys from several sources; cross-source fuzzy match (same amount, within 3 days, exactly one candidate committed before this ingest without a key from this source) applies to every source, generalising story 10.3.
- (decision) Cash flow inclusion predicate defined once in domain/cash-flow.ts; loan_payment and investment_contribution count as expenses as in Sure.
- (decision) Default categories seeded once at server start guarded by settings.defaults_seeded_at.
- (decision) Better Auth tables generated into packages/data/schema/auth.ts; one auth middleware; setup route creates user only when zero users in same transaction; sync route guarded by constant-time SYNC_SECRET.
- (decision) Request Zod schemas in packages/api/src/schemas importing only zod and @archant/data, reused by interface forms.
- (event) Reviewer gate ran: adversary (15 findings), rubric+reconcile (12 rules, 18 story amendments), tech currency (versions current, 3 high misfits). All clear fixes applied in revision 2.
- (decision) New AD-17: entry id never changes; ledger.absorb updates survivor in place and moves keys, taggings, transfers, recurring links; used for pending-to-booked and duplicate merge.
- (decision) Pending branch in key matching: exact key hit on a pending entry updates it in place; booked line without key hit is compared with pending entries of the same account and connection, same amount, within 5 days. Amount may change only on same-id match. Stale pending deleted after 2 missed syncs (entries.pending_missed_syncs).
- (decision) Manual entries carry no key. Non-manual sources write both ext: (when id exists) and fp: keys; exact match on either means present. Fuzzy matching is a per-statement assignment by nearest date within 3 days; ties create and flag possible_duplicate. entry_keys carries import_id and connection_id; revert deletes its keys and deletes an entry only if no key from another source remains.
- (decision) Statement balance is the bank-signed running balance; one ledger function toStoredBalance converts to AD-5 stored form. Valuation amount is the stored-form balance, never a delta. Files write a reconciliation valuation with import_id and never replace a user-entered one; bank sync rewrites the current_anchor.
- (decision) Enable Banking: externalId is entry_reference, never transaction_id; amount sign from credit_debit_indicator; status PDNG = pending, CNCL/RJCT dropped, HOLD/SCHD dropped; current anchor balance type preference ITBD then CLBD (booked, pending applied on top); account re-link via identification_hash; private key loaded with crypto.createPrivateKey then signed with jose.
- (decision) Balance direction depends on accounts.bank_connection_id not null. On disconnect the last current anchor becomes a reconciliation valuation in the same transaction. balances materialised up to max(today, latest entry date); readers use balanceOn carrying the last row forward.
- (decision) Cash flow: countsInCashFlow and direction(tx) in domain/cash-flow.ts; direction by amount sign; only the outflow leg of loan_payment and investment_contribution counts, as expense; inflow legs never count; list direction filter reuses direction().
- (decision) Ledger functions take origin user|rule|provider|sync|maintenance; only user adds locked_fields; transactions.category_origin records who set the category.
- (decision) Transfers and rejected_transfers are ledger-owned; auto-match needs mutual uniqueness; deleting or editing amount/account/currency of a side deletes the transfer; FKs onto entries and transactions are ON DELETE RESTRICT; account deletion is a ledger function.
- (decision) Auth: Better Auth admin plugin, setup via auth.api.createUser guarded by an atomic claim of settings.setup_completed_at; role additionalFields input false; schema generated once with the auth CLI (usePlural, credentials table renamed auth_accounts) then hand-maintained; /api/auth/* outside the envelope and AppType; Hono csrf middleware on mutating routes.
- (decision) Sync: /api/sync exempt from session, secret only; button calls POST /api/bank-connections/:id/sync; lease bank_connections.sync_started_at (10 min) gives 409 SYNC_IN_PROGRESS; minimum 1 hour between syncs of one connection except forced renewal; banner when last successful sync older than 48 hours.
- (decision) Imports: preview stores bytes and options in imports with status previewed; confirm by id re-runs ingest and answers 409 IMPORT_PREVIEW_STALE when counts differ; previewed imports older than 24 h purged at start. Lines before the opening anchor rejected BEFORE_OPENING_DATE, preview offers to move the opening date. Key lookups batched per statement.
- (decision) Logging: only ids and counts, never business objects or provider payloads; redact full header paths; a test serialises representative errors and greps for amount and IBAN patterns. IBAN stored masked. Losing ENCRYPTION_KEY means reconnecting banks.
- (decision) Web calls relative /api; Vite proxy in development, no CORS, WEB_ORIGIN dropped. SPA fallback mounted after /api with JSON 404. SQLite pragmas foreign_keys ON, WAL, busy_timeout; write transactions BEGIN IMMEDIATE. Static ISO 4217 minor unit table. settings.reporting_currency default EUR. Provider dates take the literal date part. ACCOUNT_TYPES const in @archant/data with classification and subtypes, type details in a Zod-validated JSON column. CLI scripts in packages/api/src/cli. Coverage 100% branches on domain, ledger, connectors. scaffolding-lessons.md binding.
