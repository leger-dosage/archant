- (event) Fast path: project owner granted autonomy on 2026-09-21. Direction given: shadcn/ui with Tailwind 4, inspiration Sure and Linear, departures from Sure allowed, French first, WCAG 2.2 AA and keyboard use.
- (decision) Form factor: responsive web, desktop first; phone supports reading and quick edits [ASSUMPTION].
- (decision) UI system: shadcn/ui on Radix, base colour neutral, Tailwind 4 CSS variables; brand layer only overrides primary, accent, radius, fonts, and adds money semantics.
- (decision) Typography: Geist and Geist Mono as in Sure, via @fontsource-variable packages; amounts always tabular figures.
- (decision) Palette: monochrome surfaces as in Sure (grays from Sure tokens), one indigo brand accent #444CE7 (Sure indigo.600) for focus, active navigation, links and first chart series [ASSUMPTION]. Income amounts in green #078C52 (Sure green.700) with a plus sign; expenses in foreground colour with a minus sign, never red. Red reserved for destructive actions and errors.
- (decision) Surfaces Linear-like: flat, 1px borders, almost no shadow; sidebar on a gray surface, content on background. Radii 4/6/8 px.
- (decision) Dark mode supported, follows the system with a manual override [ASSUMPTION].
- (decision) IA: left sidebar with Tableau de bord, Comptes (accounts listed under it, grouped assets/liabilities with balances as in Sure), Opérations, Récurrences, Règles, then Réglages (Banques, Catégories, Marchands, Étiquettes, Sécurité). Entries appear when their epic ships. Account detail with tabs Opérations, Soldes, Imports, Paramètres.
- (decision) Keyboard-first as in Linear: Cmd/Ctrl+K command palette, g+letter navigation, j/k row movement, x select, e edit, c category, n new transaction, i import, / search, ? shortcut sheet.
- (decision) Transaction editing in a right-side Sheet as in Sure's drawer; category and merchant editable inline from the row through a combobox.
- (decision) Import flow: dialog opened from an account, steps Fichier, Colonnes (CSV only), Aperçu with tabs per group and counts, confirm; toast links to history where revert lives.
- (decision) Voice: French, vouvoiement, short sentences, buttons as infinitive verb plus object, no exclamation marks, no emoji [ASSUMPTION].
- (decision) Money and dates: fr-FR format '1 234,56 €', right aligned; list grouped by day headers 'Aujourd'hui', 'Hier', 'lundi 15 septembre'. Pending shown muted with an 'En attente' badge; excluded shown muted with an eye-off icon and label.
- (decision) Privacy mode that blurs amounts, from Sure, noted as a later candidate, not in scope.
- (decision) Charts: Recharts through shadcn chart, line for balances and net worth, horizontal bars for categories; every chart has a visible summary and a table alternative.
- (change) Income green moved from Sure green.700 #078C52 (4.30:1 on white, fails AA) to #067647 (5.69:1 on white, 5.31:1 on #F7F7F7). Dark mode income #32D583 (9.37:1 on #171717), accent dark #8098F9 (7.29:1).
