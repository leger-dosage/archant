# Getting help

Archant is maintained by one person, in their spare time. There is no paid support.

1. Read [docs/troubleshooting.md](docs/troubleshooting.md): it lists the problems self-hosters meet, with the exact message and the fix. [docs/deployment.md](docs/deployment.md) covers installation, upgrades, backups and connecting a bank.
2. If it does not help, open a [bug report](https://github.com/leger-dosage/archant/issues/new?template=bug.yml) with the version, how you run Archant, and the steps. Never paste real bank data, a token or a cookie.
3. A security flaw is never reported in an issue: follow [SECURITY.md](SECURITY.md).

GitHub Discussions are off for this repository: questions go through a bug report or a [feature request](https://github.com/leger-dosage/archant/issues/new?template=feature.yml).
