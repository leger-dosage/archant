# BMAD planning archive

These files record Archant's planning, design, implementation and review before the switch to OpenSpec. To resolve an old path in an archived document, replace its `_bmad-output/` prefix with `docs/archive/bmad/`.

- [Epic plan](planning-artifacts/epics.md) and [feature inventory](planning-artifacts/feature-inventory.md) record the original scope and acceptance criteria.
- [Implementation artifacts](implementation-artifacts/) hold the story decisions, review notes and manual test fixtures.
- [Sprint status](implementation-artifacts/sprint-status.yaml) records the status at migration. The [OpenSpec backlog](../../../openspec/README.md#pending-changes) tracks the proposals that were still pending.
- [Deferred work](implementation-artifacts/deferred-work.md) records findings and ideas that had no approved implementation plan, along with their evidence and any recorded resolution.

The [OpenSpec specifications](../../../openspec/specs/) describe current behaviour. The [architecture decisions](../../architecture.md) remain in the architecture document.
