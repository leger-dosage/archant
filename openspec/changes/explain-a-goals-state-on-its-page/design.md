## Approach

Build the header, lifecycle actions and projection copy from the same goal state and pace used for the chart.

Use the contract introduced by `a-goals-pace-and-history-as-sure` (Story 35.9). An unknown pace cannot justify catch-up advice or a projection line. A measured zero can reflect deposits and withdrawals that cancel, so the subtitle describes net savings.

Keep Archant's progress figures and history chart, including for reached goals and reserves. The state panel explains when money remains earmarked. Its closure action uses the existing confirmation, and its edit actions open the existing goal dialog. Viewers can read the explanations.
