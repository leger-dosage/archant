## Approach

Keep the existing import flow and validation on narrow screens. Adapt the column mapping and preview inside the dialog. Reuse the rule list and editor at every width, including the rule preset link and run history. Keep the same permissions, loading and error states. Where a preview table needs horizontal scrolling, contain it within the dialog and keep the step actions reachable.
